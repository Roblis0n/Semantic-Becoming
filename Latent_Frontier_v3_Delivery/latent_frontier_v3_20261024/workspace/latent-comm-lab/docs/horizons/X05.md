原始输入及历史快照不覆盖；作用域只允许局部研究状态。新 ontology、ISA、frame、world、task、evidence 不能相互代替。未来神经源代码可以绑定这些对象，但本轮没有初始化、下载、载入、前向、训练、评测或 API 调用。

## 4. 假设依赖图

```text
A1（对象定义） ──→ A2（跨对象作用保持前提）
        ╲                 │
          ─────────────→ A3（有限表示与实际程序） ──→ H1（未来学习假设，未运行）
```

- **A1 [definition]**：An explicit synthetic world mutation request, ontology and versioned protocol seed exist. 依赖：无。
- **A2 [conditional_bridge]**：New conceptual and instruction definitions must be bound to generated task semantics and retain synthetic lineage. 依赖：A1。
- **A3 [finite_derived]**：A finite generation schedule registers four separate version axes with dependency invalidation. 依赖：A1, A2。
- **H1 [unrun_learning_hypothesis]**：Future models may co-adapt to these changing languages without an a priori fixed vocabulary; NOT_RUN. 依赖：A3。

A2 的条件不因接口类型相同而自动成立。A3 的有限程序和正反例只覆盖声明域；H1 不是 A1–A3 的定义，更不是已证结论。意识、主体体验、人格连续性或一般智能都不由该 DAG 自动推出。

## 7. 三条更远的结构分叉

- **同类型网络扩展**：更多种群与世界：增加生态位但保留任务差异；单一赢家指标会抹平生态；需要多样性谱系和不确定迁移图。
- **对象类型演化**：语言对象演化：允许新概念类型和指令定义；固定解释器边界失效；需要可还原的基础语义与读者版本契约。
- **任务环境与语言共同演化**：环境与语言共变：任务生成器也被修订；固定题库不再是参照；需要保存原始任务而非通过变容易获得进展。

三条分叉分别改变规模、对象本体和任务生成条件。它们引入不同的不变量破坏与新控制层，不是“把模型做大”的三个同义版本。外部目标、用户授权、执行政策和预算权限始终在研究对象之外，不能由演化程序自行改写。
