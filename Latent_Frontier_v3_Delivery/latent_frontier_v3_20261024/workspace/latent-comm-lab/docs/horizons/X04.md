## 4. 假设依赖图

```text
A1（对象定义） ──→ A2（跨对象作用保持前提）
        ╲                 │
          ─────────────→ A3（有限表示与实际程序） ──→ H1（未来学习假设，未运行）
```

- **A1 [definition]**：Source/target public tangent anchors, a bounded learning rule and explicit causal module interfaces exist. 依赖：无。
- **A2 [conditional_bridge]**：Transport preserves only the reachable linearized behavior; residual and update cost remain visible. 依赖：A1。
- **A3 [finite_derived]**：A finite rule/budget compiler and an SCM graft can be connected by a named operational effect contract. 依赖：A1, A2。

A2 的条件不因接口类型相同而自动成立。A3 的有限程序和正反例只覆盖声明域；H1 不是 A1–A3 的定义，更不是已证结论。意识、主体体验、人格连续性或一般智能都不由该 DAG 自动推出。

1. 将不同 token 下标当公共行为锚，会破坏运输的坐标语义；当前程序拒绝锚不一致。
2. 目标切空间不覆盖源方向时，正则化或裁剪不能制造可达性；SCM 嫁接本身也不能证明未运行神经更新的因果效果。

若输入前提不满足，程序保留对应反例、错误或未决状态；不根据经验结果缺失删除该方向，也不以“未来可能有效”掩盖当前逻辑错误。

## 7. 三条更远的结构分叉

- **同类型网络扩展**：更多规则节点：允许有限更新网络和循环；局部下降不保证全网稳定；需要组合 Lyapunov 或明确反例。
- **对象类型演化**：可塑性对象演化：规则新增记忆、梯度估计器和变量；固定内循环签名失效；需要规则类型、所有者和停止梯度证明义务。
- **任务环境与语言共同演化**：世界与规则共变：学习改写局部因果模块，模块改变训练任务；固定分布假设失效；需要联合谱系和不可变外部目标。

三条分叉分别改变规模、对象本体和任务生成条件。它们引入不同的不变量破坏与新控制层，不是“把模型做大”的三个同义版本。外部目标、用户授权、执行政策和预算权限始终在研究对象之外，不能由演化程序自行改写。
