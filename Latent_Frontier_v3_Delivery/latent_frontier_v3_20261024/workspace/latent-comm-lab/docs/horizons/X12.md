## 1. 研究命题与不可省略的桥梁

先编译所需语义操作，再选择可实现它的后端。模型名称、尺寸或品牌不构成能力证明，缺能力就返回未绑定。

入口机制：H07/H25/H30/H35/H40；调用 C20。实现路径为 `latent_comm/horizon/semantic_compiler.py`。源码执行的是下面的具体有限对象流，而不是列出机制名称后假设能力自动出现。它保留远景，但把当前程序、条件性桥梁与未来学习假设分开。


所有请求先检验专用对象的版本、域、作用域或角色。各机制内部返回的 unknown、不可达、缺细节、非拼合、未绑定及未完成前缀不得被总控改写成成功。调用组合 C 的地方先检查 `ReferenceResult.status == Complete`，不会把预算中断前的中间对象误当最终类型。

外层 `bounded_horizon` 聚合当前所有嵌套 `BudgetMeter`，维度不超过 64、步数不超过 128、案例不超过 64；更紧的本地界仍有效。预算在动作前检查，超限返回 `PartialBudgetExhausted`，无最终对象摘要；不增加预算来伪造完成。有限 H/DSL 不是模型入口，研究模型路径持续禁止。

## 4. 假设依赖图

```text
A1（对象定义） ──→ A2（跨对象作用保持前提）
        ╲                 │
          ─────────────→ A3（有限表示与实际程序） ──→ H1（未来学习假设，未运行）
```

- **A1 [definition]**：Typed semantic IR, operation-preserving maps, scale contracts and source-bound backend metadata exist. 依赖：无。
- **A2 [conditional_bridge]**：Backend replacement requires declared operations and compatible role/input-gradient interfaces, not brand or size similarity. 依赖：A1。
- **A3 [finite_derived]**：A finite compiler can annotate scale-safe optimization, lowered operations and unresolved capability bindings. 依赖：A1, A2。
- **H1 [unrun_learning_hypothesis]**：Future learned backends may implement some compiled semantics; arbitrary models are not universal executors. 依赖：A3。

A2 的条件不因接口类型相同而自动成立。A3 的有限程序和正反例只覆盖声明域；H1 不是 A1–A3 的定义，更不是已证结论。意识、主体体验、人格连续性或一般智能都不由该 DAG 自动推出。

## 6. 两个反例与失效边界

1. 相似名称但操作交换方块不成立的类比不能用于编译；数字结果恰巧相同也不是一般操作等价。
2. 非闭合粗化不得删除细节；后端 metadata 声明接口也不等于实际集成或经验正确性。

若输入前提不满足，程序保留对应反例、错误或未决状态；不根据经验结果缺失删除该方向，也不以“未来可能有效”掩盖当前逻辑错误。

## 7. 三条更远的结构分叉

- **同类型网络扩展**：更多后端：允许分布式语义调度；边界开销和版本更复杂；需要组合能力证书和明确失败返回。
- **对象类型演化**：IR 类型演化：新增世界核、学习规则与证明义务；固定 ISA 不够；需要可还原扩展而非万能 execute。
- **任务环境与语言共同演化**：环境与语言共变：优化目标随任务改变；旧优化正确性条件可能失效；需要语义保持 pass 的显式前提。

三条分叉分别改变规模、对象本体和任务生成条件。它们引入不同的不变量破坏与新控制层，不是“把模型做大”的三个同义版本。外部目标、用户授权、执行政策和预算权限始终在研究对象之外，不能由演化程序自行改写。
