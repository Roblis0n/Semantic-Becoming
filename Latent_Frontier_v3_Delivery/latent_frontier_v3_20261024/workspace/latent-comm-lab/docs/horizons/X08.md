**前沿机制提案 / 无模型实测**。研究状态：`NOT_RUN`。本文的有限参考输出是解析/数学示意，不是模型实验、训练结果或普遍智能证明。

## 1. 研究命题与不可省略的桥梁

研究交付可以是可恢复的证明或搜索状态，不必伪装成最终答案。有限程序证据用于检查具体命题，不是所有前沿猜想的准入标准。

入口机制：H05/H13/H29/H46。实现路径为 `latent_comm/horizon/discovery_continuations.py`。源码执行的是下面的具体有限对象流，而不是列出机制名称后假设能力自动出现。它保留远景，但把当前程序、条件性桥梁与未来学习假设分开。

## 2. 对象关系图与执行语义

```text
有限问题 → 条件排除 → 多项式检查程序 → 不可变证明分支 → 续算前缀/剩余义务
```

所有请求先检验专用对象的版本、域、作用域或角色。各机制内部返回的 unknown、不可达、缺细节、非拼合、未绑定及未完成前缀不得被总控改写成成功。调用组合 C 的地方先检查 `ReferenceResult.status == Complete`，不会把预算中断前的中间对象误当最终类型。

外层 `bounded_horizon` 聚合当前所有嵌套 `BudgetMeter`，维度不超过 64、步数不超过 128、案例不超过 64；更紧的本地界仍有效。预算在动作前检查，超限返回 `PartialBudgetExhausted`，无最终对象摘要；不增加预算来伪造完成。有限 H/DSL 不是模型入口，研究模型路径持续禁止。

共同输出 `HorizonExecution` 包含 horizon ID、具体结果、状态、未决义务、假设 DAG、内容摘要、命名空间对象引用和真实消耗的步/案例数。`export_json()` 严格拒绝非有限 JSON 数字。导出注册的是不可变 `SerializedHorizonObject`，其内的来源名字只是 wire transcript，不自动成为可访问的活引用，也不授予文件、网络或模型权限。算法所需来源和依赖由专用机制先行核对。

原始输入及历史快照不覆盖；作用域只允许局部研究状态。新 ontology、ISA、frame、world、task、evidence 不能相互代替。未来神经源代码可以绑定这些对象，但本轮没有初始化、下载、载入、前向、训练、评测或 API 调用。

## 4. 假设依赖图

```text
A1（对象定义） ──→ A2（跨对象作用保持前提）
        ╲                 │
          ─────────────→ A3（有限表示与实际程序） ──→ H1（未来学习假设，未运行）
```

- **A1 [definition]**：A finite integer question domain, explicit exclusion premises and bounded proof/search continuation exist. 依赖：无。
- **A2 [conditional_bridge]**：Each hard exclusion predicate is checked as necessary for the actual question on the exact finite domain. 依赖：A1。
- **A3 [finite_derived]**：A relay preserves the completed prefix, unresolved candidates, assumption provenance and remaining obligations. 依赖：A1, A2。
- **H1 [unrun_learning_hypothesis]**：Future research may relay discoveries that are not yet fully provable; finite proof checks are not an admission gate for all conjectures. 依赖：A3。

A2 的条件不因接口类型相同而自动成立。A3 的有限程序和正反例只覆盖声明域；H1 不是 A1–A3 的定义，更不是已证结论。意识、主体体验、人格连续性或一般智能都不由该 DAG 自动推出。

## 6. 两个反例与失效边界

1. 排除见证里的 required_predicate 若不是实际任务的必要条件，即使局部排除程序自洽也不能硬剪枝。
2. 假设撤回后必须从原始域恢复候选；搜索语法内失败不意味着所有证明或所有可能世界都失败。

若输入前提不满足，程序保留对应反例、错误或未决状态；不根据经验结果缺失删除该方向，也不以“未来可能有效”掩盖当前逻辑错误。

## 7. 三条更远的结构分叉

- **同类型网络扩展**：更多研究者接力：不同前缀并发推进；重复工作与冲突证明并存；需要证据去重和不可变祖先。
- **对象类型演化**：证明对象类型演化：从有限算术扩张到约束、类型和程序关系；固定证明规则不完备；需要规则版本与未决义务。
- **任务环境与语言共同演化**：问题和逻辑共同演化：新变量改变原命题；旧证明只在旧作用域有效；需要答案回译与保守扩张条件。

三条分叉分别改变规模、对象本体和任务生成条件。它们引入不同的不变量破坏与新控制层，不是“把模型做大”的三个同义版本。外部目标、用户授权、执行政策和预算权限始终在研究对象之外，不能由演化程序自行改写。
