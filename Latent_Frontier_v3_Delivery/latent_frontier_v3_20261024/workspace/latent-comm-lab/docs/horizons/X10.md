## 4. 假设依赖图

```text
A1（对象定义） ──→ A2（跨对象作用保持前提）
        ╲                 │
          ─────────────→ A3（有限表示与实际程序） ──→ H1（未来学习假设，未运行）
```

- **A1 [definition]**：Typed agent capabilities, a source-deduplicated value game and an arithmetic dependency graph exist. 依赖：无。
- **A2 [conditional_bridge]**：Joint value and capability availability depend on the declared membership and shared source identities. 依赖：A1。
- **A3 [finite_derived]**：Finite join/leave events update executable plans and explicitly mark missing complementary roles. 依赖：A1, A2。
- **H1 [unrun_learning_hypothesis]**：Future systems may hold useful capabilities relationally; this is neither cryptographic non-theft nor immunity to distillation. 依赖：A3。

A2 的条件不因接口类型相同而自动成立。A3 的有限程序和正反例只覆盖声明域；H1 不是 A1–A3 的定义，更不是已证结论。意识、主体体验、人格连续性或一般智能都不由该 DAG 自动推出。

## 7. 三条更远的结构分叉

- **同类型网络扩展**：更多临时联盟：资源与依赖约束交叉；单体边际贡献不稳定；需要不同联盟下的条件贡献而非永久排名。
- **对象类型演化**：能力对象类型演化：加入新的中间类型和超边；固定角色表失效；需要类型化组合、版本和局部撤销。
- **任务环境与语言共同演化**：任务环境共同演化：联盟创造新任务；价值函数本身改变；需要保存价值定义来源而不是把数字当货币。

三条分叉分别改变规模、对象本体和任务生成条件。它们引入不同的不变量破坏与新控制层，不是“把模型做大”的三个同义版本。外部目标、用户授权、执行政策和预算权限始终在研究对象之外，不能由演化程序自行改写。
