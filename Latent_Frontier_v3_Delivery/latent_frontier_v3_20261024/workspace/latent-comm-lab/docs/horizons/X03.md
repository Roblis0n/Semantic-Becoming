## 1. 研究命题与不可省略的桥梁

新问题不按措辞不同计数。程序要求新谓词严格分裂原先不可区分的一对假设，并保留未覆盖的类比域和被拒绝的候选。

入口机制：H27/H29/H30/H45。实现路径为 `latent_comm/horizon/problem_invention.py`。源码执行的是下面的具体有限对象流，而不是列出机制名称后假设能力自动出现。它保留远景，但把当前程序、条件性桥梁与未来学习假设分开。

## 2. 对象关系图与执行语义

```text
公开观测记录 → 可执行谓词 → 假设响应分区；问题 IR → 有见证改写图；操作图 → 部分交换图
```

所有请求先检验专用对象的版本、域、作用域或角色。各机制内部返回的 unknown、不可达、缺细节、非拼合、未绑定及未完成前缀不得被总控改写成成功。调用组合 C 的地方先检查 `ReferenceResult.status == Complete`，不会把预算中断前的中间对象误当最终类型。

外层 `bounded_horizon` 聚合当前所有嵌套 `BudgetMeter`，维度不超过 64、步数不超过 128、案例不超过 64；更紧的本地界仍有效。预算在动作前检查，超限返回 `PartialBudgetExhausted`，无最终对象摘要；不增加预算来伪造完成。有限 H/DSL 不是模型入口，研究模型路径持续禁止。

## 4. 假设依赖图

```text
A1（对象定义） ──→ A2（跨对象作用保持前提）
        ╲                 │
          ─────────────→ A3（有限表示与实际程序） ──→ H1（未来学习假设，未运行）
```

- **A1 [definition]**：Finite hypotheses have public observable records, a question IR, a typed analogy and a bounded predicate grammar. 依赖：无。
- **A2 [conditional_bridge]**：A candidate question is new only if its response partition strictly separates a previously indistinguishable pair. 依赖：A1。
- **A3 [finite_derived]**：The finite procedure produces typed question edges, permitted measurements and retained rejected candidates. 依赖：A1, A2。
- **H1 [unrun_learning_hypothesis]**：A future model may learn to construct useful new observables beyond the declared grammar; NOT_RUN. 依赖：A3。

A2 的条件不因接口类型相同而自动成立。A3 的有限程序和正反例只覆盖声明域；H1 不是 A1–A3 的定义，更不是已证结论。意识、主体体验、人格连续性或一般智能都不由该 DAG 自动推出。

## 6. 两个反例与失效边界

1. 未授权字段不能进入测量；缺字段得到 unknown，不可强制变成 false 或虚构确定似然。
2. 类比图存在破坏的交换方块时，表面名称相似不足以运输操作；可靠但不完备的问题边不能升级为等价。

若输入前提不满足，程序保留对应反例、错误或未决状态；不根据经验结果缺失删除该方向，也不以“未来可能有效”掩盖当前逻辑错误。

## 7. 三条更远的结构分叉

- **同类型网络扩展**：更多观测操作：扩大有限测量组合；贪心信息增益不再保证全局最优；需要带成本的可辨识性界。
- **对象类型演化**：问题类型演化：新增变量、因果干预和程序化测量；固定答案空间失效；需要依赖类型和答案回译关系。
- **任务环境与语言共同演化**：任务/环境共变：测量可能改变被测世界；静态响应表失效；需要将实验设计和世界生成联合建模。

三条分叉分别改变规模、对象本体和任务生成条件。它们引入不同的不变量破坏与新控制层，不是“把模型做大”的三个同义版本。外部目标、用户授权、执行政策和预算权限始终在研究对象之外，不能由演化程序自行改写。
