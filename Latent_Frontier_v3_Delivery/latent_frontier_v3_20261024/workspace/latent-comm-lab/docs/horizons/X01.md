## 4. 假设依赖图

```text
A1（对象定义） ──→ A2（跨对象作用保持前提）
        ╲                 │
          ─────────────→ A3（有限表示与实际程序） ──→ H1（未来学习假设，未运行）
```

- **A1 [definition]**：One owned scalar cell, a finite named program, declared participants and invertible frame changes exist. 依赖：无。
- **A2 [conditional_bridge]**：The explicit behavioral scalar and program continuation preserve the chosen operational identity, not personality or consciousness. 依赖：A1。
- **A3 [finite_derived]**：At most three handoffs and one program operation per handoff are represented with atomic state/continuation commits. 依赖：A1, A2。
- **H1 [unrun_learning_hypothesis]**：Future models may learn to use such identity-preserving interfaces; no model has been run. 依赖：A3。

A2 的条件不因接口类型相同而自动成立。A3 的有限程序和正反例只覆盖声明域；H1 不是 A1–A3 的定义，更不是已证结论。意识、主体体验、人格连续性或一般智能都不由该 DAG 自动推出。

## 7. 三条更远的结构分叉

- **同类型网络扩展**：更多分区：新增异步交接和租约；原子可见性不再由单进程保证；需要明确并发冲突与分布式恢复假设。
- **对象类型演化**：身份对象类型演化：从标量作用锚进入异构图/程序；固定状态类型不再充分；需要可组合模拟关系而非同维矩阵。
- **任务环境与语言共同演化**：任务与语言共变：身份锚随任务迁移；固定锚等价不再充分；需要保留旧锚的条件化身份谱系。

三条分叉分别改变规模、对象本体和任务生成条件。它们引入不同的不变量破坏与新控制层，不是“把模型做大”的三个同义版本。外部目标、用户授权、执行政策和预算权限始终在研究对象之外，不能由演化程序自行改写。
