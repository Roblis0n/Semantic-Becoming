# 轨迹不变量 分岔与双边约束

对应 F06、H28、H33、H34；研究 NOT_RUN。本章保留非收敛轨迹作为对象，同时不把数值振荡或性能跳点当作认知相变。

## 连续动力学的精确范围 D06

在 R^d 上令 E∈C²，K∈R^{d×d}、Kᵀ=−K，向量场 f(z)=−∇E(z)+Kz 局部 Lipschitz，故给定初值在最大存在区间有唯一经典解。全局存在需额外增长/有界性条件，不能仅从局部 Lipschitz 推出。

dE/dt=∇Eᵀf=−‖∇E‖²+∇EᵀKz。只知 K 反对称得到 zᵀKz=0，不能推出 ∇EᵀKz=0。若 E=‖z‖²/2，∇E=z，才得 dE/dt=−‖z‖²。若 E=0 则纯旋转 dz/dt=Kz，d‖z‖²/dt=2zᵀKz=0。

反例 Q=diag(1,4)、E=zᵀQz/2、K=[[0,−6],[6,0]]、z=(1,1)。∇E=(1,4)，−‖∇E‖²=−17，∇EᵀKz=18，故能量导数 +1。它完全满足 Q 正定和 K 反对称，所以一般 E 单调下降声明错误。

然而对线性系统 ż=(−Q+K)z、Q≥0，有 d‖z‖²/dt=−2zᵀQz≤0。欧氏范数与 Q 能量是两种不同不变量。当前 H33 同时记录两者，不能选一条下降曲线代替另一条。

## 积分器 D06b

显式 Euler 的纯旋转步 z⁺=(I+hK)z，‖z⁺‖²=‖z‖²+h²‖Kz‖²，除 Kz=0 外会增能。二维 K=[[0,−1],[1,0]]、z=(1,0)、h=1 得 (1,1)，范数平方从 1 变 2，是离散伪迹。

以下步长 h>0。隐式中点令 m=(z⁺+z)/2，z⁺−z=hKm，即 (I−hK/2)z⁺=(I+hK/2)z。I−hK/2 可逆：若其核含非零 x，则 xᵀx=(h/2)xᵀKx=0，矛盾。范数差 (z⁺−z)ᵀ(z⁺+z)=2hmᵀKm=0。对 −Q+K 同理为 −2hmᵀQm≤0。这个线性二次性质不说明任意非线性 E 都被中点严格保持。

当前 `h33_reciprocal/reference.py::integrate` 只实现二次 Q 与 skew K 的线性系统，矩阵求解和有限轨迹读出。`finite_return_candidate` 只是有限容差下回到旧状态，不证明存在吸引极限环；纯旋转连续周期与采样序列精确周期也不同。轨迹平均会将整个旋转周期平均为零，提示读出窗口本身是研究对象。

## 分岔与非双曲点 D06c

V(z;α)=z⁴/4−αz²/2，ż=αz−z³。在固定参数 α 下驻点满足 z(α−z²)=0。α<0 只有 0，f′(0)=α<0；α>0 出现 ±√α，f′(±√α)=−2α<0，而 0 不稳定。α=0 处 f′=0 不能由线性化判稳定；显式解 z(t)=z₀/sqrt(1+2z₀²t) 对 t≥0 收敛到 0，因此为非双曲渐近稳定。负初值符号由 z₀ 保留。

Euler 在稳定驻点附近的乘子是 1+h f′。α>0 的非零分支要求 |1−2hα|<1，即 0<hα<1；连续稳定不能保证任意步长离散稳定。α(t) 变化时，上述驻点稳定性是 frozen-parameter 分析，不自动推出动态控制路径跟随。结构变量 κ、版本迁移与连续分岔又是另一层：目前 H28 的 `migrate_structure` 接收显式给定事件，未证明网络会自主发现结构分裂。真正的热力学相变还需极限和序参量，有限多项式分岔不等于物理普适类。

## 保留的不同分岔对象：Hopf 与折叠 D06e

为避免把概念退休、合并同义标成动力学分岔，这里另给两种真正不同的有限维对象。它们是标准正规形的条件推导，不是 H28/H33 当前实现或新数学。未来分叉为 X11-B4、X11-B5。

Hopf 型：在 R² 上设 r²=x²+y²，ω≠0，ẋ=(μ−r²)x−ωy，ẏ=ωx+(μ−r²)y。原点是驻点；r>0 时，ṙ=(xẋ+yẏ)/r=μr−r³，θ̇=(xẏ−yẋ)/r²=ω。对 μ>0，r*=√μ，径向导数 μ−3r*²=−2μ<0，因此圆 r=r* 是径向吸引的周期轨道，周期 2π/|ω|。该轨道是轨道稳定，不会把不同初相位收敛为一个点；要保持多节点相对相位需另有关系或耦合。μ<0 时原点局部稳定；μ=0 时 ṙ=−r³ 仍向零吸引，不能只看纯虚线性特征值就说存在非零极限环。删掉非线性径向项后，纯 skew 旋转的每个半径都保持，却没有吸引半径。这两种周期计算不是同一机制。把周期相位关系用于概念读出仍需 A_TRAJECTORY_READOUT。

折叠/迟滞型：在 R 上取 ẋ=μ+x−x³。驻点满足 μ=x³−x；线性导数 f_x=1−3x²。|x|>1/√3 的外支稳定，|x|<1/√3 的内支不稳定。折叠位置由 f=f_x=0 联立得 (x,μ)=(1/√3,−2/(3√3)) 与 (−1/√3,2/(3√3))。这两个点还满足 f_μ=1、f_xx=−6x≠0，因此具备一维非退化 saddle-node 局部条件。|μ|<2/(3√3) 有三实根；μ=0 时 −1、1 稳定而 0 不稳定，故相同当前 μ 不决定唯一解释分支。

缓慢升降 μ 时，已占据的稳定支可延续到折叠附近，形成历史依赖；这不是任意变化速率下的严格准静态定理。折叠附近松弛率趋零，有限速率可造成延迟，噪声可造成提前跃迁，必须另给时间尺度/噪声条件。将历史分支写入协议是新的对象提案，不允许状态分支改写用户目标或现实证据。Hopf、pitchfork、fold 具有不同维数、局部分支与读出结构，不因都叫“相变”而混合。

## 双边边界 D06d

有限状态域 S、时间 T、转移关系 R_t⊆S×S、起点集 A、公开目标集 G。定义前向 F₀=A，F_{t+1}={v:∃u∈F_t,(u,v)∈R_t}；后向 B_T=G，B_t={u:∃v∈B_{t+1},(u,v)∈R_t}。

对每个时刻，存在完整合法路径经过 s 当且仅当 s∈F_t∩B_t。必要性由前缀/后缀成立；充分性把到 s 的前缀与从 s 到目标的后缀连接，因转移只依赖当前状态和时间而合法。若存在隐藏历史约束，必须把记忆纳入状态，否则这个拼接证明失效。合法边满足 u∈F_t∩B_t、v∈F_{t+1}∩B_{t+1} 且 (u,v)∈R_t。

从 0 到 3，三步每步 +0 或 +1，唯一合法路径 (0,1,2,3)。目标改为 4 则空集。后向计算只使用已给公开目标与转移，不是从未来接收信息。对概率核，前后向 sum-product 求的是给定观测/终端事件下的条件分布，需要正归一化常数；这里源码只是有限可达性，不能把路径计数当概率后验。

H34 `solve_boundary` 返回全部已枚举路径或保留 pending 的 SolverLimit，不能把预算内第一条称唯一解。连续残差最小化只在目标值为零且硬边界成立时是精确可行路径，有限优化停步不证明全局最优。
