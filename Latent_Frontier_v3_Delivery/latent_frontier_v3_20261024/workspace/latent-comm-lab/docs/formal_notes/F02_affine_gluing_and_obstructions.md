# 仿射拼合障碍与有条件修订

对应 F02、H26，连接 H27/H36/H48；研究 NOT_RUN。结论是有限线性系统的可解性与冲突见证，不是任意知识体系具有已计算的上同调类。

## 对象与假设 D02

有限图 G=(V,E) 每个顶点持有 z_i∈R^{d_i}，边 e=(i,j) 的比较空间 R^{k_e}，限制映射 R_ie∈R^{k_e×d_i}、R_je∈R^{k_e×d_j} 和偏置 b_e∈R^{k_e}。将 z 拼为 n=Σd_i 维向量，所有边组成 Mz=b；观测硬锚为 Az=a。随机性不参与这个确定问题；把噪声解释为随机残差需要另给分布，当前最小二乘本身不等于最大似然。

硬锚先检验可行。若可行，取一个 z₀ 满足 Az₀=a，N 的列张成 ker A，则所有可行状态为 z=z₀+Nu。于是最小化 ‖Mz−b‖² 等价于最小化 ‖Bu−c‖²，其中 B=MN、c=b−Mz₀。由正交分解 c=Π_im(B)c+c_⊥，任意 u 的平方误差为 ‖Bu−Πc‖²+‖c_⊥‖²，故最小值 ‖c_⊥‖²；零残差当且仅当 c∈im B。极小 u 可能不唯一，但投影和残差唯一。若用浮点阈值判断，只得到容差内相容，不是精确代数证明。

等价的不可解证书：存在 y∈ker Bᵀ，yᵀc≠0。若 Bu=c，则 yᵀc=yᵀBu=0，矛盾。反过来 c 不在 im B 时取 y=c_⊥ 可得非零证书。该有限维正交补事实提供了清晰的失败对象，不要求出现抽象认知解释。

## 三节点反例的逐步推导

约束 x−y=0、y−z=0、z−x=1，残差 r=(x−y,y−z,z−x−1)。三分量和恒为 −1。因此由 Cauchy–Schwarz：1=(Σr_i)²≤3Σr_i²，最小平方残差至少 1/3。锚 x=0，取 y=1/3,z=2/3 得 r=(-1/3,-1/3,-1/3)，达到该界。最小二乘找到最好的折中却没有同时满足原知识。若三条约束都硬化，则无解，而不是“找到近似共识”。

无锚且 b=0 的齐次系统总有 z=0。返回这个解无法证明输入蕴含有意义共识。源码对该退化情形拒绝；这是此研究协议的非平凡性约束，并不意味着数学上不存在全局截面。遗漏重叠只说明未声明关系，不得补成一致。

## 冲突最小性的准确范围

对边标签集合 C，逐个尝试删除边；若删除后仍不相容，就保留删除，否则保留该边。给定每次可解性判定正确，最后得到 inclusion-minimal 冲突集：任一剩余单边再删都相容。理由是约束删除只会放宽可行域，某边在较大集合里不可删除，随后删其他边不会使移去它后的相容性消失。但所得集合不保证基数最小，也依赖顺序。数值阈值下还需防止近奇异条件导致相容判定不单调。当前程序明确称候选冲突集。

## 三种修订不是同一理论

1. 语境分裂：将第三边放进另一局部域。原局部结论仍保留，但不再主张它们共属同一全局变量。
2. 变量扩展：引入语境变量 b 并明确哪条观测确定 b。若仍保留 x=y=z 和 b=1，矛盾不消失；只把常数 1 改名为 b 不是修复。要么 b 是另一情境的差值，要么允许其值改变且承认原观测被修订。
3. 证据撤回：删除错误来源支持的约束，保留撤回理由及依赖失效。此举改变知识前提，不是无损解释转换。

H26→H27 的桥梁 A_CONFLICT_CAUSE：冲突可归因于缺少区分变量而不只是错误数据、单位或规则不匹配。该桥梁一般不成立，故必须让分域、扩变量、撤回和保留未决并存。不能强制所有冲突都产生概念。

## 上同调扩展如何成立

在线性图层中可明确 C⁰=⊕_iR^{d_i}，C¹=⊕_eR^{k_e}，δ⁰=M；对一维图取 δ¹=0，H¹=C¹/im δ⁰。仿射要求 Mz=b 的障碍可以是商类 [b]。有硬锚后应使用约化问题 B,c 或合适相对复形；不能直接把任意残差范数当拓扑不变量。残差依赖内积、权重和坐标，商类是不同对象。若增加二维胞腔，还必须定义 δ¹ 并证明 δ¹δ⁰=0。这是保留的未来 H/V 分支，不是当前图残差程序已完成的功能。

## 源码与主张边界

`h26_sheaf/reference.py::assemble` 使用分块限制矩阵和固定坐标锚，`_solve` 消去硬锚，`glue` 使用有界最小二乘和删除过滤。它没有实现一般锚矩阵的 nullspace 参数化、精确有理不可解证书或高阶复形；上面给出的通用推导解释有限特例并指明扩展。D02-F02 使用三节点数值特例及独立 Fraction 证书；不能以一个特例推断所有数值实例正确。

[S07, S08] 的层扩散及退化背景已由 D01 核对身份，引用键 SBV3_S07、SBV3_S08；这里只声明共享原语，不把它们的模型结果转为本项目 E。H 是障碍能否引导有用的跨模型知识组织；V 是长期不可全局拼合的集体知识。两者均未验证，但不会因尚未验证而删除。
