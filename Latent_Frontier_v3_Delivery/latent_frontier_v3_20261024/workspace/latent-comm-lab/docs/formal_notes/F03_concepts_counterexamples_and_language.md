# 概念区分与反例驱动的语言扩展

对应 F03、H27、H36，连接 H40、H47；研究 NOT_RUN。本章区分相对表达能力、信息获得、历史新颖性三个不等价问题。

## 确定语义与随机决策 D03

令有限对象域 D、旧谓词族 P₀={p₁,…,p_m}，每个 p:D→{0,1,?}。响应签名 σ₀(x)=(p₁(x),…,p_m(x))。定义 x∼₀y 当且仅当签名相等；三值中的 ? 是显式未定义值，不是 0。任何旧语言决策必须通过签名因子化：a(x)=g(σ₀(x))。若 x∼₀y 而任务要求 a*(x)≠a*(y)，则 g 收到相同输入而只能返回同一值，因此不可能同时正确。

随机策略也不能免费消除信息不足。若 Π(a|x)=K(a|σ₀(x))，则 x∼₀y 时输出分布相同。对等概率两样本且要求相反二元标签，平均准确率至多 1/2，因为 (P(output=0|x)+P(output=1|y))/2=1/2。这是已知信息限制，不是本项目发明的新下界。

新增可计算谓词 c 满足 c(x)≠c(y) 且两值都已定义，σ₁=(σ₀,c) 严格细分这对状态；存在决策 g₁ 区分该对，但未必解决全域任务。若 c 只给旧签名改名，即 c=f∘σ₀，则不可能分开旧等价类。反之若 c 使用以前没有的信息字段，表达增益伴随新增观测权限或原始信息访问，不能说纯推理从同一不可区别输入中创造了事实。

具体见证：旧谓词只问钥匙形状，两把相同形状钥匙的公开授权记录分别 expires=1、expires=3，当前时间=2。新增 c(k)=[2≤expires(k)] 可以区分。它相对旧谓词有表达增益，但 expires 已在允许的证据记录里，故没有宣称无观测地发现了撤销事实。若 expires 两条都缺失，应返回 ?，不能拿任务标签作新字段。

## 有界概念选择不是普遍最优证明

有限语法 G_B 给出候选 AST。先要求所有指定冲突对被区别，再最小化 J(c)=λ·DL(c)+μ·drift(c)；task 行为项可在未来独立监督目标加入。DL 必须是确定编码长度，drift 必须有明确定义，不能奖励概念数。当前 H27 的 `search_concept` 选择的是已检查候选中最低分，漂移代理是外延签名中 unknown 比例，不是测得历史语义漂移。有限广度/深度和枚举预算不能保证找到了整个表达语法的最优概念。

相同有限外延签名的 AST 只在 D 上等价。对 D={0,1}，x≥0 与 True 同值；加入 −1 就不同。去重可用于局部搜索缓存，不能把局部同值升级为全域同义词。`description_length` 的字符串计数是确定复杂度代理，若要信息论最短描述需补可唯一解码编码方案及语法成本，不能直接把字节数解释为普遍 MDL 最优。

## 反例引导修订 D03b

对有限域 D 和声明的布尔命题 φ，反例为 x∈D 且 φ(x)=False。若每轮记下反例集合 C_t，后续候选必须满足全部 C_t，且候选集合有限、每次排除当前失败候选，则最多检查候选数次后得到 D 上无反例候选或候选耗尽。这一终止陈述需要“累计约束”和不重复搜索两个条件，不推出存在解。

当前 H36 `revise_game` 保留历史和已使用程序，选择满足当前反例的候选并统计当前整个有限域失败数，不是通用、完整的 CEGIS 求解器。其最终 `valid_on_declared_finite_domain_only` 仅表示该域上的穷举。两程序相互不同只形成 unresolved_disagreement，不能把其中一个自动作为 oracle。两者都声称所有偶数可被 4 整除时，彼此一致但 2 就能反驳。把命题反转为“4 的倍数为偶数”是改写，必须重新验证，而不是说原命题被证真。

预算耗尽意味着有限搜索未完成，不等于无法创造概念或命题不可满足。自然任务没有可执行 oracle 时，只能留下候选反例和待确认前提，不能把多模型投票当真值。

## 版本与生命周期

本体快照 O_v 将概念 ID 绑定不可变定义。修订产生新 O_v′，读者迁移表给 old_id→new_id 或 unknown；旧对象继续由 O_v 解释。合并、拆分、退休都不自动无损。若旧概念“有权限”被拆成“临时权限”“永久权限”，旧记录没有期限字段时只能映为二者集合或 unknown，不能猜一个新类。概念删除是注册表操作，不证明神经参数已遗忘。

A_PREDICATE_GRAMMAR、A_MODEL_BRIDGE 是不同层：可执行语法里存在区分谓词不表示模型能从分歧中可靠提出它；模型生成名称也不等于可执行定义。V 是概念和协议长期共同演化，H 是可迁移区分与版本治理改善后续计算；E 均 NOT_RUN。
