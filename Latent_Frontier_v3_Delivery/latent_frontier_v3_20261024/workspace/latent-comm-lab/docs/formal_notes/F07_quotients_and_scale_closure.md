# 任务商空间与尺度闭合的条件

对应 F07、H35、H47；研究 NOT_RUN。精确行为等价、近似聚类、动态闭合和可逆还原是四个不同问题。

## 精确任务商 D07

有限非空状态域 S 和查询族 Q={q_j:S→Y_j} 给出 b_Q:S→∏Y_j。定义 s∼_Qt 当且仅当 b_Q(s)=b_Q(t)。相等的自反、对称、传递性逐项传递到此关系，故 S/∼_Q 是定义良好的商集合。Q 为空时所有状态归一类，数学合法但没有区分信息。

若 Q⊆Q′，则 s∼_{Q′}t⇒s∼_Qt。由此 π:S/∼_{Q′}→S/∼_Q，π([s]_{Q′})=[s]_Q 良定义。新类包含于唯一旧类，这是细化的精确意义；旧类到新类一般是集合值迁移，不是任选一个代表元。

S={1,2,3,4}，只问奇偶得 {1,3},{2,4}；增加是否大于 2 后得到四单元。若消息只保存奇偶，收到“奇”不能确定原数是 1 还是 3。确定解码器必须对同输入给同输出，故不可能对两种源态都恢复正确。保留来源或请求新观测才可细化；增加一个 query_id 不会凭空恢复丢失信息。

## 近似关系不能直接取商

取 ε>0，在实行为轴上定义 d(s,t)≤ε。取值 0,.75ε,1.5ε：相邻近而首尾不近，传递性失败。连通分量形成了新的等价关系，却允许一簇的直径远大于 ε；完全链接聚类可保证簇内直径，但可能依赖插入顺序且不是原关系的唯一商。当前 `approximate_clusters` 显式返回 method 和非传递见证，没有把近似等价偷换成严格等价。

只在当前查询上相同也不等于 bisimulation。若 q(a)=q(b)=0，而 F(a)=c,F(b)=d，q(c)=0,q(d)=1，下一步即可区别。要维护所有未来操作意义，需对转移闭合或递归行为关系额外约束。

## 确定闭合的充要条件 D07b

令微观动力学 F:S→S，粗化 C:S→M，宏观只定义在 C(S)。存在 F̄:C(S)→C(S) 使 C∘F=F̄∘C，当且仅当

C(s)=C(t) ⇒ C(F(s))=C(F(t))。

必要性直接把共同粗态代入 F̄。充分性对每个 m 选任意 s∈C⁻¹(m)，定义 F̄(m)=C(F(s))；纤维一致性确保与代表元选择无关。此证明不依赖线性，但只保证单步确定闭合；多步可由归纳得到 CF^k=F̄^kC。

线性仿射版本 x⁺=Fx+f，C∈R^{m×n}。要求宏观 m⁺=Gm+g 对全部 x 成立，等价于 CF=GC、Cf=g。若 C 满行秩，则存在 G 当且仅当 ker C⊆ker(CF)；因为 CF 必须对同粗态的差向量消失。若 C 非满行秩，G 在 im C 外不唯一，不能宣称唯一宏观规律。

例一 F=I,f=(1,1)、C=[1,1]，则总和每步加 2，精确闭合。例二 F=[[1,1],[0,1]],C=[1,1]。s=(1,0)、t=(0,1) 均粗为 1，但 CFs=1、CFt=2，无只依赖总和的确定闭合。低重建误差或 CL=I 都不修复该反例。

## 记忆扩展而非伪装闭合

若 C 满行秩，取右逆 L、CL=I，Q=I−LC，将 x_t=Lm_t+d_t，Cd_t=0。代入得

m_{t+1}=CFLm_t+CFd_t+Cf；
d_{t+1}=QFLm_t+QFd_t+Qf。

递归展开 d_t=(QF)^td₀+Σ_{j=0}^{t−1}(QF)^{t−1−j}(QFLm_j+Qf)。宏观更新因而含初始未解析分量与历史记忆核。只有 CFd_t 永远为零、或被新增变量充分表示，才退化为无记忆闭合。这个推导不证明能找到低维有效变量，但保留了更强的 H/V 分支而不把非闭合当方向失败。

当前 H35 `coarsen` 定义 detail=x−LCx，因此不论 L 是否右逆，`refine` 代回都重建 x；这种代数恒等式需要保存完整 detail，不是压缩后免费反演。该实现没有强制 CL=I，故上面的 ker C 记忆解释只在补充右逆条件下适用，不能直接套给任意配置。

## 概率闭合

有限 Markov 核 K(s,t)、分区 C。宏观 Markov 核存在且对所有初始微分布适用的一个精确条件是 strong lumpability：对任意同块 s,t 和目标块 B，有 Σ_{u∈B}K(s,u)=Σ_{u∈B}K(t,u)。此时定义 K̄(C(s),B) 为共同值，非负且行和为 1；对任意分布求和得到下一步块分布仅取决于当前块分布。只对某一平稳初分布成立是更弱问题。当前 H35 是确定仿射版，不是一般随机 lumpability 检查器。
