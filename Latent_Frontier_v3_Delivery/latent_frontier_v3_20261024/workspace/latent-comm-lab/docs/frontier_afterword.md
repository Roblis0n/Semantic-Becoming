## 三条主线的不同增长方式

主线 A 不只造新名词：分别改变可计算谓词、问题的解关系、知识逻辑、操作语法和跨版本解释。主线 B 不只搬参数：分别改变可达行为方向、学习度量、更新规则状态和能力主体边界。主线 C 不只合成更多文本：分别改因果模块、机制编辑、噪声 coupling 和任务生成语法。

主体、语言、学习、世界、时间可以联合变化，但用户目标、预算、数据边界与外部权限属于不可被研究对象改写的控制面。时间分叉只讨论偏序执行、路径条件化和轨迹读出，不主张未来信息倒流；主体分叉只讨论计算身份和责任，不主张意识。

### X11-B4 由 Hopf 环上的相位关系定义动态概念

新对象：PhaseConceptAtlas=(amplitude,relative_phase,periodic_readout,phase_invariant_contract)，概念驻留于稳定周期轨道及相位关系而非单个固定点。

3. 把共同时移视为同一相位参考变换，读出相对相位。

### X11-B5 折叠分岔与迟滞的历史依赖概念

需求 P24 / X11；机制 H27, H28, H39, H40；书面核对 D02-BRANCH-X11-B5（不执行未来算法）。

新对象：HystereticConcept=(control,stable_branch,history,fold_conditions)，同一当前控制值可以因历史位于不同稳定解释分支。

算法与推导路线：
1. 以 xdot=mu+x-x³ 定义可分析的分支图。
2. 在 x=±1/sqrt(3) 找折叠并标注外支稳定/内支不稳定。
3. 用缓慢升降控制形成不同分支继承路径，明确绝热条件和失稳延迟。
4. 将分支历史写入消息，必要时对两个合法解释并行推理。

新增条件：读出区分稳定分支；变化足够慢才可近似准静态迟滞；有噪声时需另给跃迁语义。

必须保留：历史依赖不是任意改目标，外部事实与权限不随分支改变。

区分见证：mu=0 时 x=±1 均稳定而 x=0 不稳定；只传 mu 不传分支无法唯一恢复状态。

未证明桥梁：标准灾变/迟滞理论不主张原创，真实认知语义的状态变量和控制参量尚未识别。
