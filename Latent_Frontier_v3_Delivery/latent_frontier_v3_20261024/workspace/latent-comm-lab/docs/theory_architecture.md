# Semantic Becoming: first-principles architecture


前沿机制提案 / 无模型实测。Architecture is source/design, not an empirical result.


## Computational boundary

The research plane changes typed states, available operations, concepts, questions, internal views, clocks, worlds, update rules and evidence. It never changes the user goal, host permissions, spend or current model-run prohibition. An effect declares read/write sets, preconditions, postconditions, provenance and either an inverse or an information-losing migration.


## Object graph

Public role view → validated typed object → scoped proposal → bounded candidate branch → effect bundle → evidence lineage → versioned transaction. Concept changes insert ontology migration; macro changes lower into immutable base ISA; problem rewrites carry answer relations; world changes retain shared-noise identity.

## Non-unification is deliberate

A shared constraint field may be appropriate for H04 while H26 preserves incompatible local theories. Invertible H25 transport is not H35 compression. H33 can produce meaningful periodic trajectories without a fixed point. H29 sound solution transport is not automatically complete equivalence. H48 provenance is not truth or independence.

## Implementation discipline

Each mechanism owns dedicated types/reference/adapter/losses/schema/tests/recipe. Tensor code is written and AST-checked but not imported or executed. All shared contracts are stdlib-only. The compiler performs seven independently diagnosed passes; bounded research loops are distinct from the authoring DAG. Receipts hash outputs and dependencies. Changes invalidate descendants.
