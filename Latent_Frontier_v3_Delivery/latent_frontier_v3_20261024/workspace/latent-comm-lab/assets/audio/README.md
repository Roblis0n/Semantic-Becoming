TTS.ai / MeloTTS / ZH，普通合成声，不模仿真人。60 次已受理提交共 1,811 个字符，对应 58 段、1,754 个不重复源字符；额外提交（如有）仅为明确批准的缺失音频替代，不能抹掉原任务。仍有 2 个历史提交远端结果未知；这是原提交状态，不表示最终音频缺失。实际响应 credits_used 均为 0。请求证明已经移除临时下载 URL 与能力标识，只保留公开输入、设置、状态、费用计数、许可与音频哈希。

真实边界：实际试听、专有词发音和听感审查尚未完成，尚无已建立的真实听审证据。已测响度、削波、静音段，已完整解码；这些不等于试听。P17 的强制试听仍是明确验收阻塞。
