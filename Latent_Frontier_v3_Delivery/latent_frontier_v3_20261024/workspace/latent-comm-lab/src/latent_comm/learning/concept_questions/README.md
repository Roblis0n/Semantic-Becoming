# L04: concepts and questions, source only

The executable predicate AST remains the meaning of a concept. Grammar enumeration
selects a candidate with actual encoded description length, distinguishing pairs,
and an explicit old-reader drift term. Continuous relaxation trains only the
thresholds and a concept readout; its gradients are exact for the relaxation, not
for discrete AST selection. W03 uses canonical query order and keeps target
predicate values and required pairs exclusively in SupervisionBatch. The old
reader has its own consistency term; a new concept is not a silent redefinition.

Question learning predicts independent soundness/completeness bits and trains an
explicit affine answer map. A discrete proposal selector samples from the public
domain and uses a stopped, baseline-subtracted score-function advantage. It does
not receive solved answers or verified relation labels before the loss. A
classifier is not a proof: H29's finite QuestionGraph verifier, failure retention
and answer-transport obligations still decide semantic admissibility. Structural
search is bounded and separate from continuous optimization; no straight-through
estimator is claimed. This W04 source binding learns one-step choices; the full
bounded graph source supports longer checked paths.

Every objective has its own owner, numerator, denominator, mask, estimator and
units in the mechanism loss ledger. Description length is an exact discrete
candidate score and a constant within one continuous phase, never a fake tensor
gradient. Explicit phase weights appear in configs/learning/concept_questions.json.
The shared engine handles AdamW, freezing, valid accumulation, clipping and
safe tensor-only resume. `--describe` is safe metadata; all other paths require
future authorization and are hard-denied now. No datasets, models or neural
fixtures were initialized or executed. Research state: NOT_RUN.
